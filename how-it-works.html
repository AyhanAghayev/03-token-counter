How an LLM Works

From the moment you press Enter to the first word of the response, here is what happens inside a large language model.

  1. 1

    User Input

    You type a prompt and submit it. This raw text is sent to the model's API as plain text, waiting to be interpreted.

  2. 2

    Tokenisation

    The tokeniser breaks the text into tokens: small chunks of roughly 3 to 4 characters. "Hello, world!" becomes ["Hello", ",", " world", "!"]. Each token is then mapped to a unique integer ID.

  3. 3

    Embedding

    Each token ID is looked up in an embedding table and converted into a high-dimensional vector. These numbers encode the semantic meaning of the token in a form the network can work with.

  4. 4

    Attention Layers

    The vectors pass through dozens of transformer layers. At each layer, the attention mechanism lets every token look at every other token and decide which ones matter for its meaning in this context.

  5. 5

    Prediction

    The final layer produces a probability for every token in the vocabulary. Sampling settings such as temperature decide how boldly the model picks from that distribution.

  6. 6

    Output Generation

    The chosen token is appended to the prompt and the whole process repeats, one token at a time, until the model emits a stop token. That is why responses stream in word by word.
